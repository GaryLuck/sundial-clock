# sundial-clock
An interactive, educational game and sandbox where you can explore the relationship between solar/lunar time, latitudes, seasons, and celestial shadows.

## Features
- **Interactive Analog Clock**: Drag the clock's hour or minute hands to change the time.
- **Mathematically Accurate Sundial**: A 3D horizontal sundial face dynamically recalculates its hour lines and projects shadows based on your set time, latitude, and season.
- **Dynamic Atmosphere**: Watch the sky change from dawn, daytime, dusk, to starry night with an arc-moving Sun and Moon.
- **Moondial Mode**: Engage moondial dialing under full moon conditions at night.
- **Educational Academy Challenge**: Play a 5-level campaign to test your mastery of celestial alignments.
- **Sandbox Mode**: Explore the effects of seasons (Solstices/Equinoxes) and latitudes (Cairo, New York, London, Oslo).
- **Sound Effects**: Real-time synthesizer feedback utilizing the Web Audio API.

## How to Run
Simply open `index.html` in any web browser! No installation or web server required.
